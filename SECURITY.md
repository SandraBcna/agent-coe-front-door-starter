# Security

Do not report security concerns through public GitHub issues.

This repository is a community reference template without a guaranteed support or response SLA. If you identify a potential vulnerability in the template, use GitHub's private vulnerability reporting feature when available.

For vulnerabilities in Microsoft products or services, follow the Microsoft Security Response Center reporting process:

https://msrc.microsoft.com/report/vulnerability/new

Never include credentials, tokens, customer data, restricted documents, tenant identifiers, or other sensitive information in a public report.
